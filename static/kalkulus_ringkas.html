Bagian 1: Pertidaksamaan
1. 5 ≤ 2x + 1 < 17
5 - 1 ≤ 2x < 17 - 1
4 ≤ 2x < 16
2 ≤ x < 8
➔ HP = [2, 8) (2 ikut, 8 tidak)
2. 3x - 7 > 2x + 5
3x - 2x > 5 + 7
x > 12
➔ HP = (12, ∞) (lebih besar dari 12)
3. x² - 4x - 5 < 0
(x - 5)(x + 1) < 0
Akar: x = 5 atau x = -1
Tanda < 0 ➔ ambil tengah
➔ HP = (-1, 5) (antara -1 sampai 5)
4. (x - 2) / (x - 5) ≤ 0
Pembilang: x = 2 (tertutup)
Penyebut: x ≠ 5 (terbuka)
Daerah negatif: 2 ≤ x < 5
➔ HP = [2, 5) (5 tidak boleh ikut)
5. |2x - 1| < 7
-7 < 2x - 1 < 7
-6 < 2x < 8
-3 < x < 4
➔ HP = (-3, 4) (antara -3 dan 4)
6. |2x - 6| ≤ 8
-8 ≤ 2x - 6 ≤ 8
-2 ≤ 2x ≤ 14
-1 ≤ x ≤ 7
➔ HP = [-1, 7] (tertutup dari -1 ke 7)
Bagian 2: Fungsi Dasar
1. Pilihan relasi fungsi
Domain {1, 2, 3} tidak boleh mendua.
➔ Jawaban: B. {(1,4), (2,5), (3,6)} (tepat 1 pasangan)
2. Banyak fungsi A={1,2,3} ke B={a,b}
Rumus = n(B)^n(A)
= 2³ = 8
➔ Jawaban: 8 fungsi
3. Apakah {(2,5), (4,7), (6,9), (8,11)} fungsi?
Domain {2, 4, 6, 8} punya tepat 1 kawan.
➔ Jawaban: Ya, FUNGSI (domain tidak bercabang)
4. Banyak fungsi P={a,b,c,d} ke Q={1,2,3}
Rumus = n(Q)^n(P)
= 3⁴ = 81
➔ Jawaban: 81 fungsi
5. Relasi 1→2, 2→4, 3→6
1 = 1/2 dari 2, 2 = 1/2 dari 4, 3 = 1/2 dari 6
➔ Jawaban: Relasi "Setengah Dari" (atau f(x) = 2x)
6. Pernyataan yang merupakan fungsi
Satu siswa hanya punya 1 nomor induk.
➔ Jawaban: A. Setiap siswa dipasangkan dengan satu nomor induk
Bagian 3: Fungsi Lanjutan
1. f(x) = 3x - 2
a. f(5) = 3(5) - 2 = 15 - 2 = 13
b. f(-2) = 3(-2) - 2 = -6 - 2 = -8
➔ Jawaban: a = 13 | b = -8
2. g(x) = ax + 4, g(3) = 19. Nilai a?
3a + 4 = 19
3a = 15
a = 15/3 = 5
➔ Jawaban: a = 5
3. h(x) = 2x² - 3x + 1. Hitung h(4)
h(4) = 2(4)² - 3(4) + 1
= 2(16) - 12 + 1
= 32 - 12 + 1 = 21
➔ Jawaban: h(4) = 21
4. f: x → 5x + 1. Rumus & bayangan 7
Rumus: f(x) = 5x + 1
f(7) = 5(7) + 1 = 35 + 1 = 36
➔ Jawaban: Rumus f(x)=5x+1 | Bayangan = 36
5. p(x) = 4x - 7, domain {1, 3, 5}. Range?
p(1) = 4(1) - 7 = -3
p(3) = 4(3) - 7 = 5
p(5) = 4(5) - 7 = 13
➔ Jawaban: Range = {-3, 5, 13}
6. f(x) = 2x + 5, f(m) = 21. Nilai m?
2m + 5 = 21
2m = 16
m = 16/2 = 8
➔ Jawaban: m = 8
