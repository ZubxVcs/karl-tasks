Halaman 1: Pertidaksamaan
1. 5 ≤ 2x + 1 < 17
5 - 1 ≤ 2x < 17 - 1
4 ≤ 2x < 16
2 ≤ x < 8
Jadi, himpunan penyelesaiannya adalah HP = { x | 2 ≤ x < 8 } atau [2, 8)
2. 3x - 7 > 2x + 5
3x - 2x > 5 + 7
x > 12
Jadi, himpunan penyelesaiannya adalah HP = { x | x > 12 } atau (12, ∞)
3. x² - 4x - 5 < 0
(x - 5)(x + 1) < 0
Pembuat nol: x = 5 atau x = -1
Uji garis bilangan: -1 < x < 5
Jadi, himpunan penyelesaiannya adalah HP = { x | -1 < x < 5 } atau (-1, 5)
4. (x - 2) / (x - 5) ≤ 0
Bentuk pecahan: x - 2x - 5 ≤ 0
Pembilang: x = 2 (tertutup)
Penyebut: x ≠ 5 (terbuka)
Daerah negatif: 2 ≤ x < 5
Jadi, himpunan penyelesaiannya adalah HP = { x | 2 ≤ x < 5 } atau [2, 5)
5. |2x - 1| < 7
-7 < 2x - 1 < 7
-6 < 2x < 8
-3 < x < 4
Jadi, himpunan penyelesaiannya adalah HP = { x | -3 < x < 4 } atau (-3, 4)
6. |2x - 6| ≤ 8
-8 ≤ 2x - 6 ≤ 8
-2 ≤ 2x ≤ 14
-1 ≤ x ≤ 7
Jadi, himpunan penyelesaiannya adalah HP = { x | -1 ≤ x ≤ 7 } atau [-1, 7]
Halaman 2: Fungsi Dasar
1. Manakah relasi berikut yang merupakan fungsi?
Syarat fungsi: setiap anggota domain tidak boleh mendua.
• A, C, D bukan fungsi (ada domain yang punya 2 pasangan).
• B fungsi (semua domain {1, 2, 3} tepat punya 1 pasangan).
Jadi, pilihan yang benar adalah B. {(1,4), (2,5), (3,6)}
2. A = {1, 2, 3} dan B = {a, b}. Banyak fungsi dari A ke B?
n(A) = 3
n(B) = 2
Banyak pemetaan = n(B)^n(A) = 2³ = 8
Jadi, banyak fungsi yang mungkin dari A ke B adalah 8 fungsi.
3. Apakah relasi {(2,5), (4,7), (6,9), (8,11)} merupakan fungsi?
Domain = {2, 4, 6, 8}
Setiap anggota domain punya tepat satu pasangan (tidak ada yang dobel).
Jadi, relasi tersebut merupakan FUNGSI.
4. Banyak fungsi dari P = {a, b, c, d} ke Q = {1, 2, 3}?
n(P) = 4
n(Q) = 3
Banyak pemetaan = n(Q)^n(P) = 3⁴ = 81
Jadi, banyak fungsi dari himpunan P ke Q adalah 81 fungsi.
5. Diagram pemetaan: 1 → 2, 2 → 4, 3 → 6. Tentukan relasinya!
Perhatikan hubungan domain ke kodomain:
1 = 12 dari 2
2 = 12 dari 4
3 = 12 dari 6
Jadi, relasi tersebut adalah "Setengah Dari" (atau rumus fungsi f(x) = 2x).
6. Manakah yang merupakan fungsi?
Fungsi mengharuskan setiap domain tepat punya satu kawan di kodomain.
Jadi, pilihan yang benar adalah A. Setiap siswa dipasangkan dengan satu nomor induk.
Halaman 3: Fungsi Lanjutan
1. f(x) = 3x - 2. Tentukan f(5) dan f(-2)
a. f(5) = 3(5) - 2 = 15 - 2 = 13
b. f(-2) = 3(-2) - 2 = -6 - 2 = -8
Jadi, nilai f(5) = 13 dan f(-2) = -8
2. g(x) = ax + 4 dan g(3) = 19. Tentukan nilai a!
g(3) = a(3) + 4 = 19
3a = 19 - 4
3a = 15
a = 153 = 5
Jadi, nilai a adalah 5.
3. h(x) = 2x² - 3x + 1. Hitung nilai h(4)!
h(4) = 2(4)² - 3(4) + 1
h(4) = 2(16) - 12 + 1
h(4) = 32 - 12 + 1 = 21
Jadi, nilai h(4) adalah 21.
4. f: x → 5x + 1. Tentukan rumus fungsi dan bayangan dari 7!
Rumus fungsi: f(x) = 5x + 1
Bayangan dari 7: f(7) = 5(7) + 1 = 35 + 1 = 36
Jadi, rumus fungsinya f(x) = 5x + 1 dan bayangan dari 7 adalah 36.
5. p(x) = 4x - 7 dan domain {1, 3, 5}. Tentukan range-nya!
p(1) = 4(1) - 7 = -3
p(3) = 4(3) - 7 = 5
p(5) = 4(5) - 7 = 13
Jadi, daerah hasil (range)-nya adalah { -3, 5, 13 }
6. f(x) = 2x + 5. Jika f(m) = 21, tentukan nilai m!
f(m) = 2m + 5 = 21
2m = 21 - 5
2m = 16
m = 162 = 8
Jadi, nilai m adalah 8.
