3. Perhitungan Operasi Bitwise 8-Bit
Data Biner: A = 11001010, B = 10101100

a. Operasi Bitwise AND (&)

Aturan: Menghasilkan bit 1 jika dan hanya jika kedua bit masukan bernilai 1.

Biner A1 1 0 0 1 0 1 0
Biner B1 0 1 0 1 1 0 0
A & B (AND)1 0 0 0 1 0 0 0

b. Operasi Bitwise XOR (^)

Aturan: Menghasilkan bit 1 jika kedua bit masukan saling berlainan nilainya.

Biner A1 1 0 0 1 0 1 0
Biner B1 0 1 0 1 1 0 0
A ^ B (XOR)0 1 1 0 0 1 1 0
Hasil Akhir:
AND: 10001000 | XOR: 01100110
